# SpicyEat 4K Design References

These are 4K-class upscaled visual references generated during the SpicyEat design process.
Use them as visual implementation references for Claude Code.

They are NOT production UI assets and should not be embedded as screenshots in the application.
Recreate the layouts as responsive React/CSS interfaces.

The visual language is:
- Sunbeam-inspired editorial food experience
- SpicyEat-original identity
- warm cream, orange, lavender and charcoal
- oversized display typography
- premium food photography
- playful copy
- smooth motion
- strong whitespace
- interactive food storytelling
